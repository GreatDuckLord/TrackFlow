TrackFlow helps you effortlessly track all your packages in one clean, intuitive Android app built with Flutter.

**Modern Package Tracking App for Android** built with **Flutter** & **Dart**.

TrackFlow helps you effortlessly monitor all your packages in one beautiful, intuitive interface. Never miss a delivery again.

## ✨ Features

- **Real-time Package Tracking** – Get live updates from multiple carriers
- **Smart Notifications** – Instant alerts when package status changes
- **Barcode/QR Scanner** – Quickly add packages by scanning
- **Beautiful Dashboard** – Clean, modern UI with dark/light theme support
- **Delivery History** – Complete tracking timeline
- **Multi-Carrier Support** (add the ones you support)
- **Offline Mode** – View cached tracking data
- **Material You Design** – Fully adaptive to Android 12+ dynamic colors
